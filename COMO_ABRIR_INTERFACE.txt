Clínica Exemplo — nova interface

1. Extraia o ZIP e abra o terminal na pasta extraída que contém iniciar_interface.py.
2. Instale o Flask: python -m pip install Flask
3. Inicie a interface: python iniciar_interface.py
4. Abra http://127.0.0.1:5000 no navegador.

Use as credenciais de demonstração que aparecem na tela de acesso.
No Windows, experimente py no lugar de python se necessário.

A nova interface usa as rotas e os formulários do projeto original.
